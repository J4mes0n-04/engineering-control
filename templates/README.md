# Общие шаблоны

Каталог содержит шаблоны артефактов, пересекающих границы сред или используемых для общего контроля.

В snapshot включены:

- передача PDE → ASE;
- обратная связь QSRE → PDE;
- Evidence Bundle;
- Definition Change;
- журнал решений;
- Outcome Check;
- план выпуска и отката.

PDE-specific шаблоны Pack и карточки Redmine остаются в PDE-репозитории. Наличие Markdown template не заменяет версионируемый JSON Schema.
