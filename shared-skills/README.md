# Общие skills

Каталог предназначен только для skills, которые одинаково применимы в PDE, ASE и QSRE и не зависят от структуры одной рабочей среды.

Текущие пять PDE skills сюда не копируются: они используют локальные PDE governance paths, templates, scripts и `workspaces/`.

Кандидат на общий skill должен:

- иметь назначенного owner;
- не изменять governance автоматически;
- явно описывать вход, выход и допустимые действия;
- работать без предположения о наличии PDE workspace;
- пройти Pull Request и проверку минимум в двух средах.
