# Машиночитаемые схемы

Каталог хранит общие версии JSON Schema и других машиночитаемых контрактов.

`pack.schema.json` скопирован из PDE baseline без смысловых изменений. До cutover PDE продолжает использовать собственную локальную копию. Будущие среды должны фиксировать используемую версию схемы по release tag и commit SHA.
